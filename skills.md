# Required Skills & Technology Stack

This project requires familiarity with the following technologies and libraries:

1. **React Native & Expo**: Building cross-platform applications (iOS, Android, Web) using Expo's managed workflow.
2. **TypeScript**: Strong typing for all components, state, and utility functions.
3. **Zustand**: Lightweight state management for global application state.
4. **React Navigation**: Stack, Tab, and Drawer navigation for React Native.
5. **ESLint & Prettier**: Enforcing code quality and formatting.

## Best Practices
- **Custom UI System**: Since we are not using a UI library, we must maintain a clean, organized custom design system with consistent spacing, typography, and colors defined centrally.
- **Component Modularity**: Keep components small, focused, and pure where possible.
- **Environment Driven**: Assume everything (brand name, primary color, API endpoints) is subject to change via environment variables.
